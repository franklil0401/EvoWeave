## 隔离原则

第二版只保存首轮 `no_go` 后的改进系统证据。第一版 108 条正式结果、运行证据和汇总报告继续保存在父目录，不能移动、覆盖或与第二版记录混合。

第二版真实运行开始后，结果文件、运行证据和汇总报告必须全部写入本目录；同一结果文件只能包含同一个系统 Git 提交和同一个任务集摘要。

## 已完成的规划审计

[规划审计报告](规划审计报告.md)包含 12 个任务 × 3 种 Agent 策略共 36 条记录，不调用模型，也不代表真实任务成功率。

- 动态策略平均 Agent 数由第一版的 1.33 降为 1.08；
- `bench-02`、`bench-03`、`bench-10` 的小型依赖范围合并为单 Agent；
- `bench-04` 的两个无依赖、明确并行范围继续使用 2 个 Agent；
- 动态难度与冻结人工标签匹配 12/12；
- 两个图片正例共向 2 个必要 Agent 暴露原图，图片负例为 0。

## 下一步真实验证

先对 `adaptive_agent + adaptive_model` 和 `single_agent + adaptive_model` 执行小规模重复复测，确认结构化输出修复与任务图收缩确实改善成功率或时延，再决定是否运行九组完整矩阵。正式 Go/No-Go 仍要求九组具有相同、完整的重复序号集合，推荐至少 3 次重复。

示例命令：

```powershell
uv run evoweave benchmark run `
  --suite benchmarks/任务集/第一版任务集.json `
  --project-root . `
  --results benchmarks/结果/第二版/真实模型结果.json `
  --agent-strategy adaptive_agent `
  --model-strategy adaptive_model `
  --trials 3
```
