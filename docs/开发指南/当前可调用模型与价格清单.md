## 1. 读表说明

“API 可发现”表示模型名称出现在当前 Key 的模型列表接口中，不保证账号已经开通推理权限；“问答实测”才表示本次确实完成了一次推理调用。

本文中的“参数规模”指模型权重参数量，不是上下文 Token 数。厂商未公开时统一写为“未公开”，不使用上下文窗口冒充参数量。价格是公开按量原价快照，不包含活动折扣、免费额度、Batch、显式缓存、Coding Plan 或资源包；实际账单以调用地域和控制台为准。

## 6. 对 EvoWeave 的当前建议

| 任务类型 | 首选候选 | 原因 |
|---|---|---|
| 高频、低风险 Worker | `deepseek-v4-flash`、`qwen3.7-flash`、`doubao-seed-2-0-mini-260215` | 三个均已实测；成本较低 |
| 高难度总调度/复核 | `deepseek-v4-pro`、`qwen3.8-max`、`doubao-seed-2-1-pro-260628` | 高能力候选，但应先做项目基准与账号授权探测 |
| 仓库级代码任务对照 | `qwen3-coder-next`、`doubao-seed-2-0-code-preview-260215` | 代码/Agent 定向模型；不能因名称自动授予写权限 |
| 截图或界面需求理解 | `qwen3.7-plus`、`qwen3.7-flash`、豆包 Seed 2.x 多模态型号 | 支持图片/视频；代码仓库仍通过受控工具读取 |

模型路由必须同时考虑任务能力、输入模态、上下文、预算、账号授权和可复现性。参数量更大不等于在本项目基准上一定更好。

## 7. 更新规则

1. 每次发布前运行三家模型发现接口；
2. 只把成功问答的模型标记为“实测成功”；
3. 价格至少每月核对一次，并记录币种、地域和阶梯；
4. 厂商未披露参数量时保持“未公开”；
5. 模型下线、重定向或权限变化时保留历史记录，不静默改名；
6. 不把任何 API Key、Authorization Header、账号 ID 或完整错误请求写入本文档。
