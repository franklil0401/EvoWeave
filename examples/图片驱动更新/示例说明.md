# 图片驱动更新示例

目标：根据界面截图修改指定前端文件。图片先经过格式、MIME、像素和单帧检查，再作为受控产物只交给声明视觉输入的临时 Agent。

```powershell
evoweave run C:\path\to\repo `
  --request "根据截图调整登录页按钮布局" `
  --path web/views/login.tsx `
  --path src/auth/session.py `
  --image C:\inputs\login.png
```

不带 `--execute` 时只执行安全摄取和固定 commit 仓库分析，不调用模型。执行时，自适应规划器只把原图放入 `web/views/login.tsx` 的视觉任务，后端文本任务不会收到图片；路由器会为视觉任务排除纯文本模型。执行前应先运行 `evoweave models doctor --network`，确认账号实际可用模型。
