# 安装与配置

## 本地安装

项目要求 Python 3.12、Git 和 uv：

```powershell
uv sync --group dev --frozen --no-editable
$env:PYTHONPATH="src"
uv run --no-editable evoweave --help
```

默认配置位于 `configs/default.yaml`。该文件采用 JSON 兼容 YAML，只保存运行目录、默认模型、沙箱镜像和确定性资源上限，不保存价格预算或密钥。`max_dynamic_tasks` 限制单次动态任务数，`split_directory_lines` 决定一个大目录写范围何时按文件规模拆分；它们是安全与资源上限，不是费用预算。

## 环境变量

系统只读取以下既有变量，不会把值写入配置、日志或报告：

- `Deepseek_api_key`
- `Doubao_api_key`
- `Qianwen_api_key`
- `EVOWEAVE_QIANWEN_BASE_URL`：可选的非密钥端点覆盖

运行 `evoweave models doctor` 只检查配置和 Key 是否存在；增加 `--network` 才会调用只读模型列表接口。

## 沙箱

默认执行要求本地已有 `evoweave-python:3.12` 镜像。系统使用 `--network=none`、只读容器根、能力删除和 CPU/内存/进程限制。当前仓库开发机没有 Docker CLI，因此真实容器运行仍是环境待办；离线测试验证命令构造和全部安全默认值。

`--trusted-host-validation` 只用于用户明确确认完全可信的本地仓库。该参数会在宿主机运行验证命令，但仍使用无 shell 白名单和清洗后的环境变量。

## 高风险批准

支付、权限、安全、数据库迁移等风险信号会让运行先进入 `waiting_for_input`。此时系统尚未检查 Docker、发现模型或调用模型。审查固定 commit、允许路径和禁止路径后，使用 `resume ... --execute --approve-high-risk` 显式继续；该参数不关闭路径、补丁或验证门禁。
