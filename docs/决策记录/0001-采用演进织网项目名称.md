# 采用“演进织网（EvoWeave）”作为项目名称

> 决策状态：已采用  
> 决策日期：2026-08-13

## 决策

项目正式采用以下名称：

| 类型 | 名称 |
|---|---|
| 中文名称 | 演进织网 |
| 英文名称 | EvoWeave |
| GitHub 仓库建议名 | `evoweave` |
| Python 包名 | `evoweave` |

## 原因

- `Evo` 表示系统服务于已有软件的持续演进，而非只从零生成项目；
- `Weave` 表示总调度 Agent 在运行时编织临时 Agent、任务依赖、上下文和补丁；
- 名称不包含“软件公司”“团队角色”等表达，符合无固定业务角色的系统设计；
- 英文名称可以直接作为仓库名、CLI 名和 Python 包名，减少多套命名造成的混乱；
- 截至决策日期的定向 GitHub 与 PyPI 精确名称检索，没有发现明显的同名 Agent 项目，但这不构成商标或全球名称可用性的法律保证。

## 影响

- 后续代码包路径统一为 `src/evoweave/`；
- 后续 CLI 建议使用 `evoweave`；
- 文档和秋招项目描述使用“演进织网（EvoWeave）”；
- 旧报告中的描述作为历史记录保留，不机械重写全部正文。
