# 单文件修复示例

目标：只允许修改一个明确文件，用最小临时 Agent 完成更新并输出补丁。

```powershell
evoweave run C:\path\to\repo `
  --request "修复 calculator.py 中 VIP 折扣的大小写匹配" `
  --path calculator.py `
  --execute
```

默认验证在无网 Docker 沙箱中执行。只有仓库完全可信时，才可显式增加 `--trusted-host-validation`。系统不会写入目标仓库主分支；最终结果保存在目标仓库的 `.runtime/artifacts/` 和 `.runtime/reports/`。
